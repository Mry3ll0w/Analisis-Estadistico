2. Estadística inferencial

2.1.1. Hipótesis nula y Alternativa

Dada la pregunta: ¿Podemos aceptar que los hombres queman en promedio más calorías en los entrenamientos que las mujeres?

Podemos plantear lo siguiente:
\(H_0: \mu_{hombres} = \mu_{mujeres}\) (La media de calorías quemadas es igual en ambos grupos).
\(H_1: \mu_{hombres} > \mu_{mujeres}\) (La media de calorías en hombres es mayor que en mujeres).

2.1.2. Justificación del test a aplicar

Dado que se va a realizar un test estadistico entre medias de muestras independientes, además desconocemos las covarianza poblacional, por tanto usaremos la covarianza muestral y un t-test.

2.1.3 Cálculos

# Calculo manual

# Separamos los grupos
hombres <- dataSet$Calories[dataSet$Gender == "Male"]
mujeres <- dataSet$Calories[dataSet$Gender == "Female"]

# Estadísticos
n1 <- length(hombres); n2 <- length(mujeres)
m1 <- mean(hombres);   m2 <- mean(mujeres)
s1 <- sd(hombres);     s2 <- sd(mujeres)

# Calculo del estadístico de contraste

se_diff <- sqrt((s1^2 / n1) + (s2^2 / n2))

# Estadístico t observado
t_obs <- (m1 - m2) / se_diff

# Aplicamos test de welch

df_welch <- ((s1^2/n1 + s2^2/n2)^2) / ((s1^2/n1)^2/(n1-1) + (s2^2/n2)^2/(n2-1))

# Valor Crítico (cola a la derecha)
t_critico <- qt(0.975, df = df_welch)

# P-valor

p_valor <- pt(t_obs, df = df_welch, lower.tail = FALSE)

# Resultados
cat("T-Critico manual:", t_critico,"\n","T-observado manual:", t_obs, "\n","P-valor manual:    ", p_valor, "\n")
## T-Critico manual: 1.960083 
##  T-observado manual: 0.5141114 
##  P-valor manual:     0.3035899
# Calculo automatico
resultado_auto <- t.test(Calories ~ Gender, data = dataSet, 
                         alternative = "greater", 
                         conf.level = 0.975)
print(resultado_auto)

4.2. Hipótesis nula y alternativa

La hipotesis nula establece que no existen difrencias en las medias de las calorías quemadas entre los diferentes entrenamientos.

La hipotesis alternativa plantea que existe al menos una de las medias de las calorias quemadas que si es diferente de las demas, quedando de la siguiente manera:

\[H_0: \mu_{\text{Cardio}} = \mu_{\text{HIIT}} = \mu_{\text{Strength}} = \mu_{\text{Yoga}}\] \[H_1: \exists \, i, j \text{ tales que } \mu_i \neq \mu_j\]

  • Workout_TypeStrength: +151.99 calorías. El entrenamiento de fuerza tiene un efecto positivo moderado, sumando 151.99 calorías adicionales en comparación con la categoría de referencia (Cardio).

  • Workout_TypeYoga: -297.30 calorías. El Yoga tiene un efecto negativo en la comparación; realizar este tipo de entrenamiento reduce el gasto calórico en 297.30 calorías respecto al Cardio para una sesión de las mismas características.

4.5 Interpretación de los resultados

Los coeficientes de las variables anteriores tienen un p-valor extremadamente bajo (<2e-16), lo que indica que el tipo de ejercicio es un predictor crítico y estadísticamente significativo del gasto calórico. Aunque el test ANOVA posterior dio un resultado más ajustado (p-valor = 0.0469), eso se debe a que la ANOVA solo mira el tipo de ejercicio de forma aislada, mientras que estos coeficientes muestran el efecto real cuando controlamos factores como la duración de la sesión y la frecuencia.

Como podemos apreciar el p-value que nos devuelve nos indica que debemos rechazar la \(H_0\): Los datos siguen una distribución normal).

Aunque tengamos este resultado con el p-value podemos seguir usando este análisis para la toma de decisiones, puesto que:

  • Tamaño de muestra (\(n\)): El dataset cuenta con aproximadamente 20,000 observaciones, lo cual supera con creces el umbral de \(n \geq 30\).

  • Teorema del Límite Central (TLC): Gracias al TLC, la distribución de la media muestral tiende a la normalidad independientemente de la distribución de los datos originales.

  • Robustez del ANOVA: Con una muestra tan grande, las desviaciones en la normalidad de los residuos tienen un impacto mínimo en la tasa de error tipo I (falsos positivos) del test F.
